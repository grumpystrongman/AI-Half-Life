# Contributing

Thank you for considering a contribution to the AI Half-Life project.

This project is designed to build a defensible public dataset and measurement framework for studying how deployed AI systems retain or lose value over time.

## How to contribute a deployment case

A case should include:

1. Organization name
2. AI use case
3. Evidence that the system was deployed or piloted in a real operational setting
4. At least one measurable post-deployment outcome
5. Follow-up duration if available
6. Public source URL
7. Suggested evidence tier

## What counts as measurable evidence

Examples:

- Active users
- Adoption rate
- Encounters processed
- Hours saved
- Minutes saved
- Manual work reduction
- Error reduction
- Revenue impact
- Cost savings
- Clinical outcome change
- Operational throughput change
- Recalibration or retirement evidence

## What does not count by itself

The following are not enough for verified inclusion:

- General AI strategy announcements
- Vendor marketing without measurable outcomes
- Model development papers with no deployment
- Press releases with no result
- Speculative use cases
- Internal anecdotes without public source

## Evidence tiers

Gold: Peer-reviewed, official, or highly detailed technical source with measurable post-deployment outcomes.

Silver: Credible public source with measurable outcomes, but not fully peer-reviewed or not deeply technical.

Bronze: Candidate or incomplete evidence requiring validation.

## Research tone

This project should stay careful, skeptical, and transparent.

Do not overstate findings.

Do not inflate sample size.

Do not treat candidate cases as verified evidence.

Do not claim the AI Half-Life framework is fully validated before the evidence supports it.

## Pull request expectations

A useful pull request should include:

- New deployment rows or outcome observations
- Source links
- Notes on evidence quality
- Clear rationale for classification
- Any assumptions or uncertainties

## Preferred contribution format

Use the schema defined in `data/data-dictionary.md`.

If you are unsure whether a case qualifies, open an issue first.

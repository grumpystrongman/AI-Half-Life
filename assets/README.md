# Assets Manifest

This folder is reserved for images and visual assets used in LinkedIn posts, the whitepaper, and conference materials.

## Current generated assets

The following images were generated for the AI Half-Life LinkedIn post series and should be uploaded here:

1. `01_ai_half_life_concept_curve.png`
   - Concept curve showing realized value decay and the 50 percent half-life threshold.

2. `02_ai_half_life_research_process.png`
   - Process diagram showing the research workflow from public deployment collection to half-life estimation.

3. `03_ai_half_life_dataset_snapshot.png`
   - Screenshot-style view of the deployment dataset.

4. `04_ai_half_life_metric_families.png`
   - Bar chart showing what metric families are commonly extracted from published deployment cases.

5. `00_contact_sheet.png`
   - Contact sheet of the LinkedIn image pack.

## Design principle

Visuals should be clean, professional, and research-oriented. Avoid hype language. The goal is to make the work look like a serious research program rather than a marketing campaign.

## Current connector limitation

The GitHub connector used to create this repository structure does not accept local binary file paths as attachments. Binary assets can be uploaded through the GitHub web UI or a local git client.

# Source Inventory Overview

This file summarizes the main source families used by the AI Half-Life project.

The formal source inventory is maintained in the research corpus workbook and source inventory CSV. This Markdown file provides a readable overview for GitHub visitors.

## Governance and responsible AI frameworks

Representative source families:

- NIST AI Risk Management Framework
- WHO health AI guidance
- CHAI responsible AI guidance and blueprint materials
- FDA good machine learning practice and lifecycle concepts
- Joint Commission / responsible AI in healthcare guidance
- ASTP/ONC hospital AI trends and governance reporting

These sources are strong on governance, safety, accountability, risk, fairness, bias, human oversight, and monitoring expectations.

## Healthcare AI adoption and deployment sources

Representative source families:

- HIMSS and Medscape AI adoption reports
- McKinsey healthcare AI implementation reports
- Deloitte healthcare AI trust and governance work
- Hospital trends in predictive AI use and monitoring
- Revenue cycle automation reports

These sources help establish that AI deployment is no longer theoretical. They also show that adoption and post-implementation monitoring are increasingly measured, though often as snapshots.

## Implementation and evaluation literature

Representative concepts:

- Evaluation beyond predictive performance
- Clinical utility
- Workflow integration
- Adoption outcomes
- Economic sustainability
- Sociotechnical implementation burden
- Long-term real-world impact

These sources are especially important because they support the argument that technical accuracy is insufficient.

## Monitoring and drift literature

Representative concepts:

- Dataset shift
- Concept drift
- Temporal performance drift
- Calibration deterioration
- Model updating
- Delayed labels
- Continuous surveillance

This literature is mature for statistical decay. The AI Half-Life project treats this as one layer of value persistence, not the whole outcome.

## Mathematical and statistical methods

Relevant methods:

- Survival analysis
- Reliability engineering
- Exponential and Weibull decay
- Statistical process control
- CUSUM and EWMA charts
- Bayesian updating
- Value-of-information analysis

These methods provide the mathematical backbone for future AI Half-Life modeling.

## Evidence quality reminder

Not all sources are equal.

This project distinguishes peer-reviewed evidence, official reports, credible news coverage, company-reported outcomes, preprints, and unverified candidates.

The point is not to gather the biggest possible list.

The point is to build a defensible dataset.

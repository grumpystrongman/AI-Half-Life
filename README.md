# AI Half-Life

AI Half-Life is an open research initiative exploring a simple question:

How long does an AI system continue creating meaningful value after deployment?

Most organizations measure accuracy, drift, fairness, and governance. This project investigates whether we can also measure value persistence, adoption decay, workflow decay, and financial value realization over time.

## Current Workstreams

- Literature review (50-100+ sources)
- Deployment case study dataset
- AI Half-Life measurement framework
- Governance and lifecycle analysis
- Conference and whitepaper development

## Research Status

This repository is under active development.

The guiding hypothesis is that a model can remain technically healthy while becoming operationally irrelevant.

Future additions:
- Verified deployment datasets
